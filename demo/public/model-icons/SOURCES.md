# Model provider icons

One SVG per OpenRouter vendor (the part of a model id before the slash), shown in the model picker.
`unknown.svg` is the fallback for vendors added later; `gemma.svg` is used for Google's Gemma models.
The icons are black on transparent; the picker inverts them in dark mode.

Licences: LobeHub icons (`@lobehub/icons-static-svg` 1.95.1) are MIT, Copyright (c) LobeHub.
The Xiaomi icon is from Simple Icons (CC0). Every logo remains a trademark of its owner and is used
only to label that owner's models. `unknown.svg` is the Lucide `box` icon (ISC).
