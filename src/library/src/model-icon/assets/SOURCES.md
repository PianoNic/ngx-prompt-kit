# Model provider icons

One SVG per OpenRouter vendor (the part of a model id before the slash), shown in the model picker,
plus one per inference provider (the platform serving the model), looked up by file name.
`unknown.svg` is the fallback for vendors added later; `gemma.svg` is used for Google's Gemma models.
The icons are black on transparent; the picker inverts them in dark mode.

Licences: LobeHub icons (`@lobehub/icons-static-svg` 1.95.1) are MIT, Copyright (c) LobeHub.
The Xiaomi icon and the provider icons marked Simple Icons are from Simple Icons 16.33.0 (CC0).
The llama.cpp and LocalAI icons are from their GitHub repos (MIT). The CoreWeave, Prime Intellect,
Open Inference and Sail Research icons are from the companies' own sites. Every logo remains a
trademark of its owner and is used only to label that owner's models or service. `unknown.svg` is the Lucide `box` icon (ISC).
